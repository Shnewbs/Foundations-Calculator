# Foundations Calculator

**Powered machines, circuit research, automation, and configurable energy systems for Minecraft 1.21.1.**

Foundations Calculator brings SonarSonic’s Calculator to NeoForge, with its required core systems integrated into one mod. Build powered processing systems, develop circuits through research, store energy, and automate machinery.

## What’s included

- **Crafting progression:** specialized crafting paths and advanced machine recipes.
- **Machines and automation:** processing equipment, generators, power cubes, and configurable item/energy sides.
- **Research and circuits:** research progression, circuit processing, and upgrades.
- **In-game field guide:** getting-started instructions, searchable entries, and recipe links; works without a separate guidebook mod.
- **Configurable power:** per-machine settings, native long-valued energy storage and transfer, and power diagnostics.
- **Modpack tools:** operator configuration inspection and optional recipe scripting.

## Requirements

- Minecraft **1.21.1**
- **NeoForge 21.1.250 or later within the 21.1 series**
- **Java 21**
- Install Foundations Calculator on **both the client and server**.

No separate Sonar Core or Foundations Guide API download is required. The required core code and guide API are included. Optional mods are not bundled and are not required for standalone play.

## Optional integrations

Integration support is included for **JEI**, **EMI**, **Jade**, **KubeJS**, and **CraftTweaker**. Optional energy adapters cover **Mekanism**, **GregTech CEu**, **Modern Industrialization**, **Applied Energistics 2**, and **GrandPower**. A Patchouli-compatible field-guide mirror is also included.

Use the Minecraft 1.21.1 NeoForge versions of optional mods and install their own required dependencies. Integration support does not mean every combination of mod versions has been tested. Check the issue tracker when assembling a large pack.

## Installation

Install the matching NeoForge version, place the release JAR in your `mods` folder, and launch with Java 21. For a dedicated server, install the same release on the server and all connecting clients. Back up existing worlds before upgrading an alpha build.
