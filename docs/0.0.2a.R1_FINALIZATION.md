# Foundations Calculator 0.0.2a.R1 — finalization changes

R1 freezes the 0.0.2a feature set and hardens the long-energy implementation for release testing.

- Preserves machine and powered-item energy above a newly lowered configured capacity across save/reload; over-capacity stores refuse new input and drain normally instead of truncating.
- Uses the public long-energy route for Calculator Screen reads, so Foundations buffers above the int FE ceiling remain visible.
- Uses long capacities in automatic storage-cube equalization and saturating capacity addition.
- Retains the HF1 640x360 normal Field Guide cap and GregTech long-storage accessor correction.
- Adds six native GameTests for machine/item serialization, legacy int promotion, public long routes and preset identity. Required runtime count is now 120.
- Replaces the stale R7 release-audit assumptions with a 0.0.2a.R1-aware JAR/source/config/GameTest gate.
- Keeps network protocol 6, all 910 recipes, registry IDs, Guide API 1.0.0 and 4,272 server settings unchanged.

Warnings from APIs that are deprecated but still required by the pinned NeoForge 21.1.250 / current 1.21.1 integration targets are not converted into risky compatibility changes merely to silence compiler output.
