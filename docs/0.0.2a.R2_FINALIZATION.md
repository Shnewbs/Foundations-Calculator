# Foundations Calculator 0.0.2a.R2 — upgrade and storage UI finalization

R2 is a bug-fix candidate on top of R1. It does not add a new gameplay system.

## Upgrade correctness

- Speed and Energy upgrades now use one shared calculation path for all upgrade-capable processing machines.
- Reinforced Furnace and Analysing Chamber previously exposed upgrade slots but their special processing methods bypassed the upgrade math; R2 fixes both.
- Machine diagnostics use the same upgraded FE cost that actual processing uses.
- Transfer Upgrade behavior remains sided, server-authoritative item export.
- Void Upgrade still acts only after ordinary output insertion remains blocked.
- Upgrade item tooltips and empty upgrade-slot hints explain the effective server-configured behavior.

## Reinforced Chest readability

The bulk-storage menu now synchronizes a count-one representative stack for each bin icon. The authoritative bulk quantity is still synchronized separately and rendered below the slot. This removes the misleading vanilla `64`/stack-size overlay seen beside the actual bin count.

## Runtime gate

R2 adds four GameTests and raises the required runtime count from 120 to **124**.
