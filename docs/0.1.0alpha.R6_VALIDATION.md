# Alpha R6 — validated bug fixes and performance pass

Completed 17 October 2026 UTC. R6 is the current alpha for all three Minecraft targets and supersedes the intermediate R4/R5 visual behavior.

The reported raw item names, red model overlay and NeoForge 26.3.0.39-beta loading rejection are fixed. Screenshot review additionally found a forced white chest outline; its first correction exposed a model-part tint regression. R6 uses the native APIs' separate overlay, white vertex tint and outline fields, and the final screenshots show normal grey chamber frames and a dark reinforced chest on both 26.x versions. Normal models have no forced outline; genuine special-item outline requests are preserved.

## Performance and gameplay scope

The [performance audit](PERFORMANCE_R4.md) records the reviewed paths, bounded allocation reductions and reproducible JVM arithmetic benchmark. Changes remove repeated upgraded-cost calculations, overflow visibility scans, unnecessary telemetry work, per-bin display inventories, geometry/table/texture identifier construction and unchanged display dirty writes. Benchmarks measure the isolated production arithmetic and do not certify whole-mod TPS/FPS gains.

The existing 910 authored recipes, default probabilities, processing times, FE costs, scan intervals, protection rules and progression remain unchanged. KubeJS 54-result tables remain covered on 1.21.1; the native ports retain datapack support. Broader copied-world migration, multiplayer/protection acceptance and long-duration performance soak remain pending, so these builds remain alpha.
