## Publication evidence format

After performing the documented checks, record `validation/0.1.0beta/acceptance.json` with the current release receipt's `source_sha256` and a `gates` object. Required gate names are `client`, `copied_world`, `survival_multiplayer`, `performance`, `port_26_1_2` and `port_26_3`. Each entry contains `status: "PASS"`, a repository-relative `evidence` path and that file's `sha256`. The audit checks every referenced artifact and the source fingerprint. Missing, stale or modified evidence keeps `release_eligible` false and automatic publication skips the candidate. Do not mark a gate PASS without running and recording its actual checks.
