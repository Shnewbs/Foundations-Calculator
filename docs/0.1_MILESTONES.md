# Cumulative 0.1a / 0.1b milestones

Each completed revision is published with matching binary/source JARs, its release audit and a source tag. Versions are cumulative. Alpha/beta numbers are not completion evidence.

## Starting point

0.0.5a is released for Minecraft 1.21.1. Compilation, JUnit and both 130-test runtime suites passed. It includes machine defaults/runtime fixes, native long-transfer scaling, onboarding advancements and operator config inspection. The 0.0.5a.R1 revision addresses high-capacity bank balancing overflow.

## Required for 0.1a

- Keep 1.21.1 working and finish the real 26.3 API migration on Java 25.
- Complete energy and inventory transaction boundaries, direction gates, transfer/conversion limits and long-operation audit.
- Verify supported JEI/Jade/scripting/technology integrations using matching platform versions.
- Finish models, textures, animation, screens and sounds; verify in the actual client.
- Prove saved inventories, energy, research and machine upgrades survive migration.
- Run survival/progression, multiplayer/protection and performance acceptance.
- Publish cumulative platform-specific artifacts after the relevant build/runtime/audit gates pass.

## Required for 0.1b

- Resolve the remaining acceptance defects through versioned revisions.
- Repeat affected platform/integration/client/migration checks and performance soak.
- Publish the cumulative beta with an explicit supported-platform matrix and known limitations.

Minecraft 26.4 preparation means isolating platform APIs. Compatibility remains unverified until an actual 26.4 build/test is available. Manual acceptance is not replaced by source checks or headless GameTests.
