# Minecraft 26.1.2 port status

This branch tracks the `0.0.5a.R2` source feature baseline on Minecraft 26.1.2 / NeoForge 26.1.2.114 / Java 25. It is a source port, not a playable release. Do not publish a jar until the full mod compiles and its Minecraft runtime tests pass.

The first local full compile reported 647 Java errors. Applying the common 26.x identifier, NBT, GUI and energy-boundary migration reduced it to 345 errors. The `testPortEnergy` suite passed against the real 26.1.2 platform. Progression validation and `git diff --check` passed.

The remaining compile errors include removed inventory APIs (`ItemStackHandler` and `IItemHandler`), recipe serialization, tool and projectile item classes, menu click types, render-state APIs, content registrations and optional integration APIs. The 345 messages include cascading errors; they are not a count of independent fixes. The next gate is a zero-error `compileJava`, followed by full build, required GameTests, client and world checks, and a versioned GitHub/CurseForge upload.
