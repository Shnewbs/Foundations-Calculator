# Minecraft 26.1.2 migration status

Version line: `port/26.1.2` from the live 1.21.1 `0.0.5a.R2` baseline. Target: Java 25, NeoForge 26.1.2.114, Minecraft 26.1.2. This is source work, not a playable binary. The 1.21.1 `main` and separate `port/26.3` version line remain active.

## Verified first compile

A local `./gradlew compileJava` with a Java 25 toolchain reached javac after replacing the removed `additionalRuntimeClasspath` Guide API configuration with `runtimeOnly`. It failed with **647 reported errors** across **66 Java files**. The most affected files are `Content.java` (90 locations), `MachineBlockEntity.java` (65), `UtilityItems.java` (52), `MachinePrograms.java` (45), and `GuideScreen.java` (27). Gradle's summary repeats the first diagnostic, so location-marker counts can differ by one.

The old 1.21.1 optional integration coordinates remain compile-only diagnostic dependencies. They do not establish 26.1.2 compatibility. Their runtime versions and mod metadata constraints must be verified separately before an integration release. The R2 attachment's earlier 805-error experiment used older 0.0.2a.R2 source; this 647-error result is from the current live 0.0.5a.R2 lineage.

## Shared 26.x migration checkpoint

The common identifier, NBT, GUI and energy-boundary migration was applied to this branch. A fresh Java 25 compile against NeoForge 26.1.2.114 reduced the full-module error count from 647 to **345**; the messages include cascading failures. The `testPortEnergy` JUnit suite passed against the real 26.1.2 platform. Structural progression validation and whitespace checks passed.

Remaining compiler work includes removed inventory handler APIs, recipe serialization, tool and projectile item classes, menu click types, render-state APIs, registration and optional integrations. No 26.1.2 jar has passed the release gates yet.

## Projectile and menu API checkpoint

The actual 26.1.2 sources place `ThrowableItemProjectile` under `projectile.throwableitemprojectile` and require an explicit `ItemStack` in its owner constructor. The old menu `ClickType` is now `ContainerInput`. Migrating both projectiles and the five affected menus reduced the local full compile from 345 to **296 reported errors**. This is still not a loadable build.

## World accessor checkpoint

The removed `DirectionProperty` type is now `EnumProperty<Direction>`, and research/guide code obtains the server through the player's level instead of the private player field. A fresh full compile after these changes reports **289 errors**. No jar is produced.

## Recipe and mod-event migration

The process recipe now uses Minecraft 26.x's record-based `RecipeSerializer` with its existing map/network codecs and implements the current `Recipe` contract. The unbreakable component uses `Unit.INSTANCE`; greenhouse seeds use the current `BlockItem` base. The former automatic mod-bus subscriptions for networking and optional integrations are explicitly registered on the mod event bus. Local full compilation reports **266 errors**. Server/client recipe lookup and other platform APIs remain unfinished; no jar was produced.
