## Performance follow-up

Nutrition network scans now use the existing per-position staggered schedule,
spreading traversal work across ticks while preserving the configured cadence.
The existing `performance.staggerWork` opt-out restores legacy tick alignment.
Block/config lookups are hoisted once per traversal and the private direction
table is reused, while loaded-chunk and protection checks remain live.

Two new unit tests verify the cadence, legacy opt-out and scan scheduling spread
for 1,000 positions. Nine Python tests cover candidate classification and upload
metadata, including rejecting automatic stable publication, an unaccepted beta,
incorrect platform metadata and incomplete native evidence.

This builds on the [earlier performance audit](../PERFORMANCE_AUDIT.md), including
the isolated allocator's 77.3% allocation reduction. Whole-world TPS/FPS gains
have not been measured. Larger magnet queries, nutrition topology caching,
locator/mast scans and renderer text caching remain candidates for profiling.

## Remaining acceptance

These are experimental alpha builds. Live-world upgrades, broad client gameplay,
multiplayer/protection and full-world performance soak remain incomplete.
The newer ports include tested matching JEI, Jade, AE2 and GuideMe; they do not
claim support for the other 1.21.1 scripting/energy integrations.
